# مهامي — تطبيق PWA

قائمة مهام وملاحظات عربية، باتجاه RTL ووضع داكن، قابلة للتثبيت على الهاتف وتعمل دون اتصال بعد أول زيارة متصلة.

## المزايا

- ستة أقسام للمهام والملاحظات، مع عرض تقويم شهري يجمع العناصر ذات المواعيد.
- إضافة العناصر، إكمالها، وحذفها؛ ويمكن إنشاء مهمة مباشرة ليوم مختار في التقويم.
- تعيين نطاق تاريخ شامل للبداية والنهاية؛ تظهر المهمة على كل يوم ضمن النطاق.
- تكرار أسبوعي باختيار أي أيام (مثل الأحد والاثنين والأربعاء)، مع تاريخ نهاية اختياري، وحفظ إنجاز كل تكرار بشكل مستقل.
- إعادة ترتيب المهام في القسم عبر زري الأعلى والأسفل.
- التنقل بين الأشهر وإضافة مهمة مباشرة ليوم محدد، مع تعديل المواعيد من بطاقة المهمة.
- حفظ محلي على الجهاز باستخدام `localStorage`؛ لا يوجد حساب أو مزامنة سحابية.
- تثبيت كتطبيق على Android من Chrome.
- تخزين ملفات الواجهة محليًا للعمل دون إنترنت.

## النشر على GitHub Pages

1. ارفع محتويات هذا المجلد إلى جذر مستودع GitHub.
2. افتح **Settings → Pages**.
3. في **Build and deployment** اختر **Deploy from a branch**، ثم الفرع `main` والمجلد `/(root)`، واحفظ.
4. افتح الرابط الذي تعرضه صفحة Pages وانتظر حتى يكتمل النشر.

## التثبيت على Android

1. افتح رابط Pages في Google Chrome مع اتصال بالإنترنت.
2. من قائمة Chrome اختر **Install app** أو **Add to Home screen**.
3. افتح التطبيق مرة واحدة ليتم تخزين ملفاته، ثم يمكن تجربة وضع الطيران.

## ملفات التطبيق والخصوصية

- `index.html`: الواجهة والسلوك.
- `app.js`: إدارة المهام والتواريخ والتقويم.
- `calendar.css`: تنسيق التقويم المتجاوب.
- `schedule.css`: تنسيق المدى والتكرار وأزرار الترتيب.
- `manifest.json`: إعدادات التثبيت والهوية.
- `sw.js`: التخزين المؤقت للعمل دون اتصال.
- `icons/`: أيقونات التطبيق.

تُحفظ بيانات المهام على الجهاز نفسه ولا تُرفع إلى GitHub أو إلى أي خادم. مسح بيانات Chrome أو التطبيق قد يحذف هذه البيانات. يتطلب Service Worker عنوان HTTPS، لذلك لا تفتح `index.html` مباشرة من مدير الملفات.

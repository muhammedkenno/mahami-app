تطبيق مهامي (PWA)
===================
الملفات:
- index.html: واجهة التطبيق والسلوك.
- app.js: إدارة المهام والتواريخ والتقويم.
- calendar.css: تنسيق التقويم الشهري المتجاوب.
- schedule.css: تنسيق المدى والتكرار والترتيب.
- manifest.json: بيانات التثبيت وإعدادات التطبيق.
- sw.js: التخزين المؤقت للعمل دون إنترنت.
- icons/: أيقونات التطبيق.

التقويم:
يعرض التقويم الشهري المهام حسب نطاق البداية والنهاية، ويمكن تحديد أيام تكرار أسبوعية ونهاية اختيارية للتكرار. اختر مثلًا الأحد والاثنين والأربعاء للنادي؛ ستظهر المهمة تلقائيًا بهذه الأيام، ويُحفظ إنجاز كل أسبوع بشكل مستقل. يمكن ترتيب المهام بأزرار الأعلى والأسفل، وتعديل الجدول من بطاقة المهمة. المهام القديمة تبقى محفوظة.

النشر:
1. ارفع محتويات هذا المجلد إلى جذر مستودع GitHub.
2. من Settings > Pages اختر Deploy from a branch.
3. اختر الفرع main والمجلد /(root)، ثم احفظ.
4. افتح رابط GitHub Pages في Chrome على Android واختر Install app أو Add to Home screen.

الخصوصية والتخزين:
تُحفظ المهام والملاحظات على هذا الجهاز فقط باستخدام localStorage؛ لا توجد حسابات أو مزامنة خادمية. قد يؤدي مسح بيانات المتصفح أو التطبيق إلى حذف العناصر المحفوظة.

يجب فتح التطبيق عبر عنوان HTTPS. لا تفتح index.html مباشرة من مدير الملفات، لأن Service Worker يحتاج إلى HTTPS أو localhost.
